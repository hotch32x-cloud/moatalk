# 모아톡

숲(SOOP) 게시글에 달린 댓글을 한곳에 모아 바로 답하는 프로그램입니다.

## 받기

[Releases](../../releases) 에서 최신 `모아톡-설치-x.x.x.exe` 를 받아 실행하세요.
설치에 관리자 권한이 필요하지 않습니다.

> Windows 가 "PC를 보호했습니다" 라고 막으면
> **추가 정보 → 실행** 을 누르세요. 아직 코드 서명 인증서를 붙이지 않아서 뜨는 안내입니다.

## 하는 일

- 내 글에 달린 댓글을 자동으로 찾아 **사람별·댓글별**로 정리합니다
- 카카오톡처럼 생긴 대화방에서 **바로 답글**을 보냅니다
- **OGQ 스티커**와 **사진**을 붙여 보낼 수 있습니다
- 숲 로그인은 앱 안의 진짜 숲 페이지에서 합니다 — 아이디·비밀번호는 이 프로그램이 만지지 않습니다

## 자료가 어디에 저장되나요

전부 본인 PC 에만 저장됩니다 (`%APPDATA%\모아톡`). 서버로 보내지 않습니다.

## 문의

프로그램에 오류 번호(`MT-101` 같은)가 뜨면 그 번호와 함께 [Issues](../../issues) 에 남겨 주세요.
번호만 있어도 어디서 막혔는지 알 수 있습니다.
